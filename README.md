# Portfólio — João Pedro Teixeira Guimarães

Meu portfólio pessoal reúne minha apresentação, tecnologias, áreas de atuação e projetos desenvolvidos durante minha trajetória em Ciência da Computação.

🌐 **Acesse a versão publicada:** [jpedrotg23.github.io/portfolio-react](https://jpedrotg23.github.io/portfolio-react/)

## Sobre o projeto

Desenvolvi este site para apresentar meu trabalho de forma organizada e profissional, reunindo projetos acadêmicos, pessoais e experiências práticas. A proposta é mostrar não apenas as tecnologias que estudo, mas também os problemas que busco resolver e os tipos de soluções digitais que posso desenvolver.

O portfólio tem identidade visual escura, detalhes em vermelho, elementos inspirados no universo de desenvolvimento e uma apresentação que prioriza clareza, personalidade e navegação.

## O que você encontra no portfólio

- **Apresentação pessoal:** formação, interesses e trajetória.
- **Tecnologias e conhecimentos:** ferramentas e linguagens organizadas por área, com ícones.
- **Serviços e soluções:** sites institucionais, landing pages, catálogos digitais, portfólios e interfaces web.
- **Projetos em destaque:** trabalhos web, mobile, jogos e ferramentas acadêmicas, com filtros por categoria.
- **Processo de desenvolvimento:** etapas de entendimento, planejamento, desenvolvimento e revisão.
- **Contato:** links para e-mail e redes profissionais.

## Tecnologias utilizadas no portfólio

- **Frontend:** React 19, JavaScript, HTML5 e CSS3.
- **Build e desenvolvimento:** Vite.
- **Animações:** Framer Motion.
- **Ícones:** Font Awesome e Devicon.
- **Qualidade de código:** Oxlint.
- **Versionamento e publicação:** Git, GitHub e GitHub Pages.

## Executar localmente

Você precisa ter Node.js e npm instalados.

```bash
# Clone o repositório
git clone https://github.com/jpedrotg23/portfolio-react.git

# Entre na pasta do projeto
cd portfolio-react

# Instale as dependências
npm install

# Inicie o ambiente de desenvolvimento
npm run dev
```

O Vite exibirá no terminal o endereço local para abrir o site no navegador.

### Outros comandos

```bash
# Verificar o código com Oxlint
npm run lint

# Gerar a versão de produção
npm run build

# Visualizar localmente a versão gerada
npm run preview
```
